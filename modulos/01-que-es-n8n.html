¿Qué es n8n?

Antes de instalar nada, vamos a entender qué es n8n, cómo "piensa" y qué tipo de tareas puede hacer por ti.

DefiniciónCómo funcionaConceptos claveComparativaEjemplosTest

Una definición sencilla

n8n (se pronuncia "n-eight-n", abreviatura de nodemation, "automatización con nodos") es una herramienta para automatizar tareas conectando aplicaciones entre sí. En lugar de escribir un programa, dibujas el proceso en un lienzo: colocas bloques llamados nodos y los unes con flechas.

Piensa en una cadena de montaje: el primer puesto recibe algo (un email, un formulario, una hora concreta del día), lo pasa al siguiente, que lo transforma, y así hasta el final. Cada puesto de la cadena es un nodo, y la cadena completa es un workflow (flujo de trabajo).

Visual

Construyes automatizaciones arrastrando nodos. Hay cientos de integraciones listas: Gmail, Google Sheets, Slack, Telegram, Notion, bases de datos…

Flexible

Cuando lo visual no basta, puedes escribir JavaScript o Python dentro del flujo, o llamar a cualquier API con el nodo HTTP Request.

Tuyo

Puedes instalarlo gratis en tu ordenador o servidor (self-hosted), de modo que tus datos se quedan contigo. También existe una versión en la nube de pago.

n8n usa una licencia fair-code: el código es público y puedes usarlo gratis para tus propios procesos o los de tu empresa, pero no revenderlo como servicio a terceros sin acuerdo con n8n.

¿Cómo funciona un workflow?

Todo workflow sigue la misma idea en tres pasos:

  1. Algo lo pone en marcha (trigger). Puede ser que pulses un botón, que llegue una hora programada, que alguien envíe un formulario o que entre un correo nuevo.
  2. Los datos viajan de nodo en nodo. Cada nodo recibe datos, hace su trabajo (filtrar, transformar, consultar una app, preguntar a una IA…) y pasa el resultado al siguiente.
  3. Se produce un resultado. Se envía un mensaje, se guarda una fila en una hoja de cálculo, se crea una tarea, se responde a una web…

Los puntos que ves moverse representan los datos pasando de un nodo a otro. En n8n esos datos viajan siempre en formato JSON, algo que veremos con calma en el módulo 5.

Conceptos clave

Este pequeño vocabulario aparecerá en todo el tutorial. Pulsa cada término para ver su explicación.

WWorkflow

El flujo completo: el conjunto de nodos conectados que automatiza una tarea. Se puede activar para que funcione solo.

NNodo

Cada bloque del workflow. Hace una sola cosa: leer un email, filtrar datos, escribir en una hoja, llamar a una IA…

TTrigger

Nodo especial que inicia el workflow: manual, por horario (Schedule), por petición web (Webhook) o por un evento de una aplicación.

CConexión

La línea que une dos nodos. Indica el camino que siguen los datos.

IItem

Cada unidad de datos que viaja por el flujo (por ejemplo, un email o una fila). Un nodo puede recibir muchos items y procesa cada uno.

KCredencial

Los accesos guardados (usuario, token, clave de API) que n8n usa para conectarse a un servicio en tu nombre. Se guardan cifrados.

EEjecución

Cada vez que el workflow se ejecuta. n8n guarda un historial para que puedas ver qué datos pasaron por cada nodo.

XExpresión

Fórmula entre dobles llaves, como {{ $json.email }}, que sirve para usar datos de nodos anteriores.

La gran ventaja de n8n para aprender es que, instalado en local, puedes practicar sin límites y sin pagar. Es justo lo que haremos en el módulo 2.

Ejemplos de lo que puedes hacer

Estos son cinco workflows típicos. Al final del tutorial serás capaz de construirlos todos.

1. Formulario → hoja de cálculo → email

Cuando alguien rellena un formulario de tu web, sus datos se guardan en Google Sheets y recibe un correo de confirmación automático.

2. Resumen diario de noticias con IA

Cada mañana a las 8:00 se leen tus fuentes RSS favoritas, una IA resume lo más importante y te lo envía por Telegram.

3. Copia automática de adjuntos

Las facturas que llegan a tu Gmail se guardan solas en una carpeta de Google Drive, con el nombre del remitente y la fecha.

4. Chatbot que responde con tus documentos

Un agente de IA atiende un chat y, antes de responder, consulta tus documentos (manuales, preguntas frecuentes) para dar respuestas correctas.

5. Vigilar que tu web funciona

Cada 5 minutos se comprueba si tu web responde. Si falla, te llega un aviso al momento.
